# Site records (static data for the site)

Generated by `python -m eqore_site.export`. One record per facility address, built from public, keyless sources: no API keys, no server.

| File | What it is |
|---|---|
| `index.json` | One row per site: facility, address, state, status, public utility, seismic, top parcel candidates, warnings, completeness summary |
| `records/<slug>.json` | `{facility, record}`: the facility-list entry plus the full site record (every value has source, vintage, confidence, note) |
| `records/<slug>.prefill.csv` | Permit packet + lead-form prefill (filled / review / missing) |
| `records.js` | `window.EQORE_SITE_INDEX` and `window.EQORE_SITE_RECORDS`, for pages opened without a server (`<script src="site_records/records.js">`) |
| `schema.json` | JSON Schema of `record` |
| `facilities.json` | Input list (facility-list fields; utility account numbers deliberately left out) |

Use from the site:

```js
const idx = await (await fetch("site_records/index.json")).json();
const site = await (await fetch("site_records/" + idx.sites[0].file)).json();
site.record.fields.find(f => f.id === "f_util");   // {display, source_label, vintage, confidence, status, ...}
```

Add or refresh an address:

- **On GitHub:** Actions → *Site records* → Run workflow → enter the address (blank rebuilds all). Or edit `facilities.json` and push. The workflow commits the results here.
- **Locally:** `pip install -r site_records/requirements.txt` then `python -m eqore_site.export --facilities site_records/facilities.json --address "16 Commerce Way, Woburn, MA" --out site_records`.

Coverage: California (statewide layers + San Francisco and Hayward parcel adapters) and Massachusetts (MassGIS statewide). Records are `needs_confirmation` until a person confirms the parcel; the tool never picks one. Flood zone is a manual FEMA lookup. Distances are screening only; no fire-code rule is applied.
